En qué consiste el sistema?

El Sistema de Biblioteca es una aplicación de escritorio escrita en Java que permite gestionar el catálogo de libros, registrar préstamos a estudiantes, controlar devoluciones y calcular multas por retraso automáticamente.

Cuenta con una interfaz gráfica construida con Java Swing dividida en pestañas: Catálogo, Búsqueda, Préstamos, Devolución, Multas y Configuración. Cada libro recibe un ID único y puede ser modificado o buscado desde la GUI.

El proyecto está estructurado en 5 clases: Libro, Prestamo, Multa, Biblioteca (consola) y BibliotecaGUI (interfaz gráfica).

Los 4 pilares de POO aplicados

Cada clase del proyecto refleja uno o más principios de la Programación Orientada a Objetos. Así es como se aplican:

Encapsulamiento

Los atributos de Libro, Prestamo y Multa son private. Solo se accede a ellos mediante getters y setters que validan los datos antes de guardarlos.

↑

Herencia

BibliotecaGUI extiende de JFrame, heredando toda la funcionalidad de una ventana de Swing sin tener que construirla desde cero.

≡

Polimorfismo

El método toString() está sobrescrito en las tres clases modelo (Libro, Prestamo, Multa), cada una con su propia representación en texto.

◈

Abstracción

La clase Biblioteca abstrae toda la lógica del negocio: registrar, prestar, devolver y calcular multas, sin que la GUI tenga que saber cómo funciona por dentro.
